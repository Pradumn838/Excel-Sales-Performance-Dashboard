# Excel-Sales-Performance-Dashboard
Interactive Excel dashboard for analyzing sales performance, target achievement, and regional trends using sales data.
An interactive Microsoft Excel Sales Performance Dashboard designed to analyze sales performance, target achievement, and regional trends across multiple sales executives.

📊 Project Overview

This project uses sales data from 141 sales executives across different regions. The dashboard helps track individual and regional sales performance against a fixed sales target.

The project demonstrates practical Excel skills including data analysis, KPI tracking, dashboard creation, and data visualization.

💡 Business Objective

The objective is to transform raw sales data into an easy-to-understand dashboard that can help management:

Monitor sales performance
Identify high and low performers
Track target achievement
Compare regional performance
Identify performance gaps
Support data-driven decision-making
